How I Work

Each project follows the same three steps, from the original data to the final recommendations.

01

Clean

The data is checked for duplicates, missing values and inconsistent records. Each issue is documented with the decision made, and the cleaned version is kept separate from the original data.

02

Analyze

The data is first explored to understand its patterns. Each key question is then answered separately using SQL, Python or machine learning, and every result is saved for review.

03

Recommend

The findings are translated into practical recommendations and presented in an interactive dashboard, along with the limitations of the analysis.
